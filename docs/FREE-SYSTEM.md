# Free autonomous infrastructure — exact capabilities

## Installed
- GitHub Actions checks code on push and pull requests.
- A six-hour readiness workflow reports missing official competition assets.
- A three-hour coordinator ranks a real task backlog and publishes downloadable artifacts.
- Node.js tests and scripts do not need model tokens or API keys.
- The repository is editable directly through the connected ChatGPT GitHub integration during active conversations.

## Not installed / impossible to claim
- No model-backed coding agent is executing unattended. Regular ChatGPT cannot be called from GitHub Actions for free using the user's ChatGPT subscription.
- No agent can autonomously turn the task queue into working code without a separately authorized model runner.
- GitHub Actions cannot independently create authentic Codex session logs for make.fun.
- No cross-repository orchestration, auto-merge, browser screenshot, official kit acquisition or final submission has been verified.

## How to operate at zero extra cost
1. GitHub runs the free coordinator and tests on schedule.
2. Review the latest Actions artifact for prioritized tasks and blockers.
3. During an active ChatGPT session, request 'work the next Token Radar queue tasks' and changes can be committed through the GitHub connector.
4. When Codex allowance resets, use it for genuine eligible authorship and the official test suite.
5. Never auto-submit or assert success without official checker results.

## Security
No secrets are committed. All workflows use read-only repository tokens, no untrusted issue execution, no model API calls, no paid dependencies, and no auto-merge.
